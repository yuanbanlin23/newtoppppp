# 条形码生成器

在线生成多种格式条形码，支持预览与下载 PNG / SVG。

## 在线访问

部署成功后打开：

**https://yuanbanlin23.github.io/newtoppppp/**

## 本地开发

```bash
npm install
npm run dev
```

## 启用 GitHub Pages（首次）

1. 打开仓库 [Settings → Pages](https://github.com/yuanbanlin23/newtoppppp/settings/pages)
2. **Build and deployment → Source** 选择 **GitHub Actions**
3. 推送 `main` 分支后，在 [Actions](https://github.com/yuanbanlin23/newtoppppp/actions) 查看部署是否成功

## 自定义域名（可选）

在 Pages 设置里填写 **Custom domain**，并在域名服务商添加 CNAME 指向 `yuanbanlin23.github.io`。
